# Как опубликовать приложение «Куда выбросить?»

Приложение должно лежать на сайте с адресом https://. Ниже — бесплатный способ через GitHub Pages, без программ и командной строки.

## Что в папке

- `index.html` — само приложение
- `manifest.webmanifest` — название, значок и цвета для установки на телефон
- `sw.js` — служебный файл, благодаря которому приложение работает без интернета
- `icons/` — значки
- `fonts/` — шрифт, чтобы он был доступен офлайн

Этот файл с инструкцией загружать не обязательно.

## Публикация (один раз)

1. Зарегистрируйтесь на github.com (бесплатно).
2. Нажмите «+» в правом верхнем углу → **New repository**. Назовите его, например, `sortirovka`. Оставьте тип **Public** и нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**.
4. Перетащите в окно браузера всё содержимое папки (файлы и папки `icons` и `fonts`, а не саму папку). Нажмите **Commit changes**.
5. Откройте **Settings** → в меню слева **Pages**. В разделе **Branch** выберите `main` и `/ (root)`, нажмите **Save**.
6. Через 1–2 минуты обновите страницу: сверху появится адрес вида
   `https://ВАШ-ЛОГИН.github.io/sortirovka/`

## Установка на телефон

Откройте этот адрес на телефоне.

- **Android (Chrome):** внизу появится кнопка «Установить» прямо в приложении. Если её нет — меню «⋮» → «Установить приложение» или «Добавить на главный экран».
- **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“».

После установки приложение открывается со своего значка, во весь экран и без интернета. Ссылкой можно делиться с семьёй и друзьями.

## Как обновить приложение

1. Загрузите изменённый файл в репозиторий тем же способом (Add file → Upload files).
2. В файле `sw.js` увеличьте номер версии: `sortirovka-v1` → `sortirovka-v2`.
   Без этого телефоны продолжат показывать старую версию.
3. На телефоне закройте и снова откройте приложение — иногда нужно сделать это дважды.

## Если открыть файл двойным щелчком на компьютере

Приложение заработает, но установить его и пользоваться офлайн-режимом так нельзя: браузеры разрешают это только для сайтов с адресом https://.
